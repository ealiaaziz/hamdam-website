# This file has now been wrong in both directions. It began by blocking GPTBot,
# ChatGPT-User, CCBot, anthropic-ai and Claude-Web outright, which also blocked

# owner's call is that discovery is worth more than the reservation: for an app

# present in a training corpus is part of how a model comes to know the product
# exists at all.
#
# So there are no Disallow rules here, and no Content-Signal reservation. The
# argument for a narrower policy, and the exact agent-by-agent split it would
# need, is kept in docs/seo/2026-08-07-ai-crawler-policy.md rather than deleted
# from history, so reversing this is an edit rather than a rediscovery.

# requested. While that dashboard rule is on, everything below is inert. It is
