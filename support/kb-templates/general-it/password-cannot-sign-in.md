id: password-cannot-sign-in
title: Cannot sign in, or the password is not accepted
symptoms:
  - cannot sign in
  - can't log in
  - password not working
  - forgot my password
  - password expired
  - locked out
  - incorrect password
clarifying:
  - Which sign-in is refusing you: the computer itself, or a website like Outlook or Teams?
  - Does it say the password is wrong, or that the account is locked or blocked?
---

Which sign-in is failing matters more than it sounds, because the computer
password and the work account password are often two different things even
when they were set to the same value.

1. Try signing in at https://outlook.office.com in a browser. If that works,
   the account and password are fine and the problem is on the device.
2. If it does not work there, use the "Forgot my password" link on the
   sign-in page. This only works if self-service reset has been switched on
   for your organisation, so if it asks for details you were never asked to
   set up, stop and reply here instead.
3. Check that Caps Lock is off and that the keyboard layout has not changed.
   A password that used to work and suddenly stops is very often this.
4. If a message says the account is locked or blocked rather than that the
   password is wrong, do not keep trying. Repeated attempts extend the lock.
   Reply here and say exactly what the message reads.

If you are being asked to change your password and the new one keeps being
refused, it is usually a rule about length or reuse rather than a fault. Say
so when you reply and we will tell you what the rule is.
